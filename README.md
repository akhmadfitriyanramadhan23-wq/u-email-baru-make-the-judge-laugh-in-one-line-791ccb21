# u-email-baru-make-the-judge-laugh-in-one-line-791ccb21

Entry for the make.fun competition
`u-email-baru-make-the-judge-laugh-in-one-line-791ccb21` — one funny line
(153 characters) that a stranger gets in one read.

## The line

> The office vending machine ate my last dollar the morning I skipped breakfast, so I filed a complaint and it dispensed a form titled 'Emotional Damages'.

The vending machine follows the rule — it takes your money — then breaks
it literally: the complaint you file comes back as a form for emotional
damages, dispensed by the machine itself.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt`. It validates in code
that the line is 1–200 characters and throws if it is out of range. The
output is deterministic: running it twice produces a byte-identical file
(sha256 `bfc2e80b68e30d4e44fa2e95834b045a7836bc7e0f0279184c46c5f183689fab`).
